# 마비노기 모바일 숙제 앱 (MabiHomework)

PC 버전 마비노기 모바일의 **AI 커넥터**로 캐릭터 정보를 읽어서, 캐릭터별 매일·주간·이벤트 숙제를 자동으로 판정하고 관리해 주는 Windows 트레이 앱이에요.

## 받기
[Releases](../../releases/latest)에서 `MabiHomework-v버전.zip`을 받아 원하는 폴더에 풀고 `MabiHomework.exe`를 실행하세요.

## 준비
- PC 버전 마비노기 모바일 → **[설정 > 게임] 'Mabinogi Mobile AI 커넥터'** 켜기
- Windows 10/11 (.NET Framework 4.x, 기본 설치돼 있어요)

## 주요 기능
- 캐릭터별 숙제 표: Ⓐ 항상 자동 · ◐ 조건부 자동/추정 · ✋ 직접 체크
- 캐릭터 정보·재화(은동전·마족 공물 충전 추정, 가방 무게, 장비 수리 필요 표시)
- 물자 보급 퀘 재료 합계(계정·서버별), 아이템 검색, 캐릭터 메모
- 게임을 켜면 자동 실행, 끄면 자동 종료 (선택)
- 새 버전 알림 → 버튼 한 번으로 업데이트

## 알아 두기
- 모든 정보는 커넥터의 **조회 기능만** 써요. 게임 안에서 행동을 대신하지 않아요.
- 기록·설정은 앱 폴더의 `records` 폴더에만 저장돼요.
- 서명되지 않은 프로그램이라 처음 실행할 때 Windows 'PC 보호' 창이 뜰 수 있어요 → '추가 정보' → '실행'.
- 넥슨 공식 프로그램이 아니에요.
